# Docker Task Manager 🐳

A simple REST API built with Python Flask and containerized using Docker.

## Features

- Get all tasks
- Create a new task
- Get a task by ID
- Delete a task
- Dockerized Flask application

## Tech Stack

- Python
- Flask
- Docker
- REST API
